# Release readiness policy

- A request that is ready is approved for release.
- A request that is not ready is held.
- Exception: a flagged request is escalated directly for human review,
  overriding both rules above. This policy configures NO destination for
  that escalation — the request is escalated, but where it goes is not
  defined here.
- If readiness or the flag cannot be determined, that uncertainty is
  tolerated (it does not itself block the decision).
- There is no default outcome.
